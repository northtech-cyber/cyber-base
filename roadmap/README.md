# 🗺️ Roadmap — Cyber Base (Nível 1)

**Objetivo:** chegar a uma candidatura a funções de entrada em Cibersegurança, com foco em **Security Operations (SOC)**, partindo do zero.

**Duração:** 11 fases, cerca de 12 semanas · **Carga:** 8 a 10 horas por semana (cerca de 1h30 por dia). O plano pode ser alargado conforme o teu ritmo.

---

## 🎯 Cargos de entrada a que este percurso prepara

- SOC Analyst L1
- Junior Cybersecurity Analyst
- Security Operations Analyst
- Junior Security Analyst
- Cybersecurity Intern / Information Security Intern
- Cybersecurity Trainee

## 🧰 Competências a desenvolver

**Técnicas**

Fundamentos de redes · TCP/IP · DNS · HTTP/HTTPS · Windows · Linux · Linha de comandos · Event IDs do Windows e noções de Active Directory · Fundamentos de Cibersegurança · Tipos de ataques e ameaças · MITRE ATT&CK e Cyber Kill Chain (noções básicas) · Autenticação e controlo de acesso · Logs · SIEM · Análise de alertas · Análise de phishing e threat intelligence · Gestão básica de vulnerabilidades · Fundamentos de resposta a incidentes · Noções básicas de Python

**Comportamentais**

Pensamento analítico · Atenção ao detalhe · Investigação · Resolução de problemas · Pensamento crítico · Comunicação · Trabalho em equipa · Organização · Curiosidade · Aprendizagem contínua

**Ferramentas essenciais**

Windows · Linux · VirtualBox (laboratório) · Wireshark · Nmap · SIEM: Splunk (prática) e Microsoft Sentinel (teoria) · VirusTotal · AbuseIPDB · URLScan.io · TryHackMe e LetsDefend (níveis gratuitos)

> Dá prioridade aos recursos gratuitos. Os recursos pagos são opcionais.

## ⭐ Portefólio final

Ao concluir o percurso, terás **dois projetos principais** e **um mini-projeto por fase**, todos publicados no GitHub com README.

| Projeto | Demonstra |
|---|---|
| **1 — Investigação de Incidente** (Fase 8) | Logs, SIEM, análise de alertas, investigação, resposta a incidentes e documentação |
| **2 — Analisador de Logs com Python** (Fase 9) | Python, análise de ficheiros, automação, identificação de eventos e resolução de problemas |

Cada projeto deve incluir: objetivo, cenário, ambiente utilizado, processo de investigação, ferramentas utilizadas, evidências, resultados, conclusões, screenshots e README.

## 🧭 Depois do Cyber Base: especializar conforme a vaga

Estes conhecimentos **não fazem parte** do percurso inicial obrigatório. Acrescentam-se conforme o cargo ou a oportunidade pretendida.

| Área | Exemplos |
|---|---|
| **Blue Team / SOC avançado** | Splunk e Microsoft Sentinel avançados, Microsoft Defender, EDR/XDR, Threat Hunting, Threat Intelligence, Malware Analysis. Aprofundado no **Nível 2** (em breve) |
| **Offensive Security / Pentesting** | Kali Linux avançado, Burp Suite, Metasploit, segurança de aplicações web, OWASP Top 10, exploração de vulnerabilidades, escalada de privilégios |
| **Cloud Security** | Azure, AWS e Google Cloud Security, IAM, Cloud Monitoring |
| **Identity & Access Management** | Active Directory, Microsoft Entra ID, IAM, Privileged Access Management |
| **Governance, Risk & Compliance** | ISO 27001, NIST, gestão de riscos, auditoria, políticas de segurança |
| **Outras** | Digital Forensics, Incident Response avançado, Application Security, DevSecOps, Security Engineering |

## 🤝 Acompanhamento North Tech

**Durante a aprendizagem e os projetos:** revisão do progresso, identificação de dificuldades, esclarecimento de dúvidas, avaliação das competências adquiridas, ajustes ao roadmap quando necessário, revisão dos laboratórios e das investigações, feedback sobre os projetos, acompanhamento da documentação e preparação do portefólio.

**Durante a entrada no mercado:** revisão do CV, otimização do LinkedIn, organização do portefólio, preparação para perguntas técnicas e análise de cenários, simulação de entrevista, preparação para a certificação de entrada (ISC2 CC ou CompTIA Security+), estratégia de candidaturas e identificação de oportunidades.
