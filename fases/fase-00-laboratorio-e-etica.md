# Fase 0 — Preparar o Laboratório e Ética

**Semana 1 (dias 1–2)** · **Carga:** 8 a 10 horas por semana · [← Roadmap](../roadmap/README.md)

## 🎯 Objetivo

Ter um ambiente seguro e legal para realizar todos os exercícios práticos do percurso.

> 💡 Esta fase é curta, mas sem ela os exercícios práticos não são possíveis.

## 📚 Temas

- VirtualBox e máquinas virtuais (VM)
- VM Ubuntu e VM Windows (versão de avaliação gratuita)
- Snapshots: guardar e repor o estado de uma VM
- Contas: GitHub, TryHackMe e LetsDefend; caderno de notas (OneNote, Notion ou Obsidian)
- Ética e lei: testar apenas sistemas próprios ou autorizados (ver o [Código de Conduta](../CODIGO-DE-CONDUTA.md))

## 🔗 Onde aprender

- **[VirtualBox — documentação oficial](https://www.virtualbox.org/manual/)** — Instalação e criação de máquinas virtuais.
- **[Ubuntu — tutoriais oficiais](https://ubuntu.com/tutorials/install-ubuntu-desktop)** — Guia de instalação do Ubuntu Desktop.
- **[Microsoft — Windows Evaluation Center](https://www.microsoft.com/evalcenter)** — Versões de avaliação gratuitas do Windows para a VM.

## 🏁 Exercício do primeiro dia (segunda-feira)

Instalar o VirtualBox e criar uma VM Ubuntu (2 GB de RAM, 25 GB de disco).

## 📬 Exercícios da semana (terça a quinta)

Os restantes exercícios práticos e as perguntas rápidas são publicados pelo mentor como **comentários na issue desta fase** (separador [Issues](https://github.com/northtech-cyber/cyber-base/issues)). Responde lá mesmo.

## 🛠️ Mini-projeto: "Laboratório Pronto" (sexta e sábado)

README no GitHub a descrever o teu laboratório: VMs, sistemas operativos, recursos atribuídos e configuração de rede, com screenshots.

**Onde entregar:** no teu `cyber-journey`, numa branch `fase-00`, em `mini-projetos/fase-00-laboratorio-e-etica/README.md`.

**O que tem de ter:**

- [ ] Lista das VMs (nome, sistema, RAM, disco)
- [ ] Tipo de rede de cada VM (NAT, Host-Only…) e porquê
- [ ] Screenshot de cada VM a funcionar
- [ ] Screenshot de um snapshot criado
- [ ] Uma frase sobre as regras éticas que vais seguir

Nesta fase fazes também o teu **primeiro Pull Request**: adiciona-te ao [`mentorados.md`](../mentorados.md). Segue o guia em [`COMO-ENTREGAR.md`](../COMO-ENTREGAR.md#adicionar-te-ao-mentoradosmd).

Quando terminares, abre um Pull Request para o teu `main` e comenta na issue da fase: `Feito: <link do PR>`. Os passos estão em [`COMO-ENTREGAR.md`](../COMO-ENTREGAR.md).

## 🎤 Apresentação (domingo)

Apresenta o mini-projeto ao mentor na sessão de domingo, em **5 a 10 minutos**:

1. Objetivo
2. O que foi feito
3. Evidências
4. O que aprendeste
5. Dificuldades
